# Brezza website

Landing page of [Brezza](https://github.com/altrdev/brezza), a battery-powered Zigbee vibration sensor for retractable awnings.

Plain HTML, CSS and JS: no build step. `index.html` is the whole page, `img/` holds the renders.

Until the main repository is public, the links to it stay inert and read "coming soon". On the day it opens, set `REPO_PUBLIC` to `true` in `index.html`.

Local preview: `python3 -m http.server 8000`, then open http://localhost:8000.
